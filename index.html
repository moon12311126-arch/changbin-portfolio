1. 전공 및 학습 목표

반도체전자계열에서 전자부품과 전자회로의 기초 동작 원리를 익히는 것을 목표로 합니다. 본 프로젝트에서는 다이오드의 순방향·역방향 특성을 바탕으로 교류 입력이 정류회로를 통과할 때 출력 파형이 어떻게 달라지는지 이해합니다.

세부 목표

  • 다이오드의 애노드와 캐소드 및 순·역방향 바이어스 개념 이해
  • 다이오드 1개를 이용한 반파 정류회로의 동작 설명
  • 다이오드 4개를 이용한 브리지 전파 정류회로의 도통 경로 설명
  • 두 회로의 출력 파형과 맥동 주기 비교

2. 회로 구성 개념

반파 정류회로

다이오드가 순방향 바이어스되는 반주기에는 부하에 전류가 흐르고, 역방향 바이어스되는 반주기에는 전류가 거의 흐르지 않습니다. 따라서 입력 교류의 한쪽 반주기만 출력에 나타납니다.

브리지 전파 정류회로

브리지 회로에서는 입력의 양·음 반주기마다 서로 다른 다이오드 두 개가 도통합니다. 부하를 흐르는 전류 방향은 두 반주기 모두 같아지므로 입력의 양쪽 반주기를 모두 출력에 이용합니다.

개념도 위 도식은 회로 원리를 설명하기 위한 단순화된 그림이며, 실제 시뮬레이터 캡처가 아닙니다.

4. 이론에 근거한 예상 결과

반파 정류

이상적인 다이오드를 가정하면 순방향 반주기에는 양의 반주기가 부하에 나타나고, 역방향 반주기에는 출력이 0V에 가까워집니다. 실제 실리콘 다이오드에서는 순방향 전압강하로 인해 출력 첨두값이 입력보다 낮습니다.

브리지 전파 정류

입력의 양·음 반주기를 모두 이용하며, 매 반주기마다 다이오드 두 개가 직렬로 도통합니다. 따라서 출력은 같은 극성의 맥동 파형이 되고, 두 다이오드의 순방향 전압강하가 반영됩니다.

비교 요약

  • 반파 정류: 입력의 한쪽 반주기만 이용
  • 브리지 전파 정류: 양쪽 반주기를 모두 이용
  • 필터가 없다면 두 출력 모두 평탄한 직류가 아닌 맥동 직류
  • 전파 정류의 출력 맥동 빈도는 반파 정류보다 두 배

실제 입력 설정값, 출력 첨두값, 평균값 등 측정 수치는 아직 확인되지 않아 기재하지 않았습니다.
